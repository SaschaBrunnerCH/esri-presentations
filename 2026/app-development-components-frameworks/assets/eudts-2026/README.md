# EUDTS 2026 artwork

Images extracted without modification from the PowerPoint at the repository root:
`EUDTS 2026 - WEB - ArcGIS Maps SDK for JavaScript App Development with Components_Using Frameworks.pptx`.

`source.json` maps each local image to its original PowerPoint ZIP entry.

The PowerPoint uses layered images rather than complete slide background bitmaps.
`../../slide-bottom.vue` and `../../theme.css` reproduce the gradients, artwork
placement, opacity, feedback screens, and copyright text in Slidev. Images remain
separate so that slide text is editable and accessible.

- Cover: PowerPoint slide 9.
- Content and feedback: slides 10–11.
- Section and social backgrounds: slides 12 and 15.
- Closing: slide 16.
- Alternate map and demo artwork: slides 18 and 22, extracted for future use.
